Stats for every StarCraft game you play

GG Stats analyzes your replays and uses that data to provide meaningful game and player stats about yourself and anyone you've played with. Live game data, Smurf detection, build order analysis, coaching based on how you play, and more.

Download for Windows

Version 1.4.2. Needs StarCraft: Remastered.

To install: winget install ggstats
